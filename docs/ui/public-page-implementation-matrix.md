## Shared acceptance contract

Every page retains its current route, query/filter behavior, data source, role/permission boundary, share/discussion behavior and SEO metadata. Every listing has loading, empty, error and image-fallback states. Every detail page has a readable main column, contextual desktop rail, ordered mobile flow and recommendations supported by relationship, taxonomy or location data.

## Recommendation rules

Resolve explicit relation first, then shared road/county/hazard/incident type/category, then a bounded recency fallback labelled as general. Filter for public visibility, moderation, current alert status and feed privacy before rendering. Do not expose private feed posts, moderated content, expired alerts as current, or unverified facts as confirmed. Mjengo previews remain external and attributed.
